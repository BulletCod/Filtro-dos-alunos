# Sistema de Filtro dos Alunos

Projeto desenvolvido em **HTML, CSS e JavaScript** que permite:

- Buscar alunos por nome, média ou faltas
- EXibir informações detalhadas de cada aluno
- Mostrar se o aluno está **Aprovado** ou **Reprovado** com base nos critérios:
  - Média ≥ 7.0 e Faltas < 7 →  Aprovado
  - Média < 7.0 →  Reprovado (Media insuficiente)
  - Faltas ≥ 7 →  Reprovado (Excesso de faltas)

## Como rodar o projeto:
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador
3. (Opcional) Use uma extensão como **Live Server** no VS Code para testar o `fetch` do `alunos.json` (O **Live server** é necessario porque tava dando bug com o fetch na hora que executava, por algum motivo no navegador não puxava os nomes da lista.)
